## 它是什么

新增一张**钻卡**植物「随机模仿者」。种下后**当场随机开出一株植物或一只僵尸** ——
它不复制任何卡，而是从全部植物和全部僵尸里直接抽一个：

- **65%** 抽到植物；
- **35%** 抽到**敌对僵尸**；
- **BOSS 和巨人也在随机池里** —— 运气不好会开出很难对付的东西。

> 植物 / 僵尸的比例**不是写死的**：可以在游戏内「Mod 管理 → 配置」里随时改，
> 保存后**立即生效**，不用重启游戏。详见下面「游戏内可调选项」。

### 为什么是钻卡

这张卡在游戏里是**钻卡**，卡面是钻卡边框，
并且享有钻卡的性质 —— **价格固定，不受常规改价机制影响**：

> 选卡界面里它会**同时出现在「Mod 植物」和「钻卡」两个页签**（两处是同一张卡，不是两张）。

## 游戏内可调选项

在游戏主菜单进入 **Mod 管理**，选中「随机模仿者」，打开**配置**即可调整：

| 选项 | 分组 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| 开出植物的概率 | 属性 | 0~100 整数（步长 5） | `65` | 出植物的概率。`0` = 只出僵尸，`100` = 只出植物 |
| 阳光消耗 | 属性 | 0~1500 整数（步长 25） | `0` | 种下这张卡消耗的阳光。`0` = 免费 |
| 随机模仿者不变白 | 显示 | 开 / 关 | 开 | 关掉游戏给模仿者产物加的黑白滤镜，保持原本配色 |

改动**保存后立即生效**，不需要重启游戏：

- **概率**：本 Mod 当场重建随机池，之后种下的按新概率。
- **阳光消耗**：卡面数字、实际扣阳光、图鉴「花费」三处同时变。
- **随机模仿者不变白**：立刻作用到场上已有的本 Mod 产物。

## 玩法

- **只有这张卡可以重复选取**。
- **本体血量 1000，会被僵尸啃咬**。

### 抽到 BOSS 会切「BOSS战」背景音乐

抽出的僵尸正好是 **BOSS** 时，背景音乐立刻切成「BOSS战」；
等这只 BOSS 倒下（多只时等最后一只），
再播放关卡原曲。这项**没有开关，始终生效**。

- 关卡本身的背景音乐已经是「BOSS战」时不做任何切换。
- 切回时原曲**从开头重播**。

### 右键放行小推车

游戏原本只在**僵尸撞上推车**时才让那一行的推车发车。装上本 Mod 后，
战斗中**用鼠标右键点在某台小推车上**，它就会立刻发车 —— 这项**没有开关，始终生效**。

- **必须点到车**：以那台推车**在屏幕上实际画出来的位置**为中心、一格大小为判定范围。
- 水面关卡的推车同样适用（同一套接口）。
- 关卡不在进行中（选卡、结算、暂停）时不响应。

## 安装

### 方式一：游戏内导入（推荐）

1. 打开游戏里的 **Mod 管理** 界面。
2. 点 **导入 Mod**，选中 `RandomImitater.pmod`。
3. 弹出确认框后点 **安装**。
4. 接着会问 **「是否启用 随机模仿者？」—— 点「启用」**。
5. **完全退出游戏再重新启动**。

> ⚠️ 第 4 步别漏。只导入不启用，Mod 不会生效（游戏启动时只加载 `enabled_mods.json` 里列出的 ID）。

### 方式二：手动安装

1. 按 `Win + R`，粘贴下面这行后回车：

   ```
   %APPDATA%\Godot\app_userdata\植物大战僵尸杂交版\Mods
   ```

2. 把 `RandomImitater.pmod` 复制进去。
3. 同目录下打开 `enabled_mods.json`（没有就新建），把 ID 加进数组：

   ```json
   ["randomimitater"]
   ```

   已经有别的 Mod 就追加，例如：

   ```json
   ["别的mod", "randomimitater"]
   ```

4. 启动游戏。

> 只把 `.pmod` 丢进 Mods 文件夹是**不够**的：启动时会扫到这个包，但 `enabled_mods.json`
> 里没有对应 ID 就不会加载。两个都要有。

## 怎么确认装上了

随便进一个关卡到选卡界面，卡片在「**Mod 植物**」和「**钻卡**」页签里。

## 卸载

在 Mod 管理界面里选中这个 Mod 删掉，或者在 `enabled_mods.json` 里把 `"randomimitater"`
那一项去掉，然后重启游戏。

只删这个 Mod 自己的文件和它那一条 ID，**不会动其它 Mod**。卸载后所有行为回到原样。

## 常见问题

**Q：装了但游戏里看不到这张卡？**

A：确认游戏版本是 0.30.0；确认 `enabled_mods.json` 里有 `"randomimitater"`；把
`%APPDATA%\Godot\app_userdata\植物大战僵尸杂交版\ModsCache\RandomImitater` 这个文件夹
删掉再重启游戏。

**Q：装完之后过一阵子 Mod 又不见了？**

A：如果游戏是**通过启动器**进去的，启动器可能会用服务器上的同名包覆盖本地文件。
直接运行游戏目录里的 exe 就不会有这个问题。

**Q：能同时装别的 Mod 吗？**

A：这个 Mod 只新增一张卡，不修改任何原有内容（`overrides` 为空），理论上不冲突。
但它和官方模仿者共用一套变身逻辑，如果另一个 Mod 也改了模仿者，可能会有相互影响。

**Q：能改概率吗？**

A：**能，而且在游戏里就能改。** 打开「Mod 管理 → 随机模仿者 → 配置」，
调整「开出植物的概率」（0~100），保存后立即生效，不用重启。

**Q：改了配置没反应？**

A：确认三点：① 点的是配置页里的**保存**（不是只改数值）；② Mod 已启用并加载成功；
③ 图鉴与卡面数字是**下次打开**时才重读，改完先关掉图鉴再打开。若都没有，把
`%APPDATA%\Godot\app_userdata\植物大战僵尸杂交版\ModsCache\RandomImitater`
删掉再重启游戏。

**Q：右键点小推车没反应？**

A：这项没有开关，装上就一直生效；先确认本关卡**确实还有没用掉的推车**
（跑完的那一行不能再放），以及关卡正在进行中（选卡 / 结算时不响应）。

**Q：右键会不会抢掉游戏自己的操作？**

A：不会。游戏里没有任何功能使用鼠标右键 —— 推车的原生输入走的是
`Input.IsActionJustPressed("Press")` 之类的动作，鼠标左键另有自己的处理器。
本 Mod 只在「按下右键的那一下」且「指针正好落在某台推车那一格里」时才动作。

**Q：为什么卡片显示的阳光默认是 0？**

A：**默认设成免费的**，因为它有一定概率开出一只**敌对僵尸** —— 如果还要照常收阳光，
就等于"花了钱还可能给自己招个敌人"，难度太高。

**Q：开出植物还要另外付阳光吗？**

A：不用额外付费 —— 开出植物或僵尸本身不再收一次阳光，只收种下这张卡的那一次
（默认 0，可在配置里调）。开出的植物直接就是你的。
