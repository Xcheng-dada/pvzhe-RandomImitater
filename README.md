## 它是什么

新增一张**彩卡**植物「随机模仿者」。种下后**当场随机开出一株植物或一只僵尸** ——
它不复制任何卡，而是从全部植物和全部僵尸里直接抽一个：

- **65%** 抽到植物；
- **35%** 抽到**敌对僵尸**；
- **BOSS 和巨人也在随机池里** —— 运气不好会开出很难对付的东西。

## 玩法

- **可以重复选取**。
- **本体血量 1000，会被僵尸啃咬**。

## 安装

### 方式一：游戏内导入（推荐）

1. 打开游戏里的 **Mod 管理** 界面。
2. 点 **导入 Mod**，选中 `RandomImitater.pmod`。
3. 弹出确认框后点 **安装**。
4. 接着会问 **「是否启用 随机模仿者？」—— 点「启用」**。
5. **完全退出游戏再重新启动**。

> ⚠️ 第 4 步别漏。只导入不启用，Mod 不会生效（游戏启动时只加载 `enabled_mods.json` 里列出的 ID）。

### 方式二：手动安装

1. 按 `Win + R`，粘贴下面这行后回车：

   ```
   %APPDATA%\Godot\app_userdata\植物大战僵尸杂交版\Mods
   ```

2. 把 `RandomImitater.pmod` 复制进去。
3. 同目录下打开 `enabled_mods.json`（没有就新建），把 ID 加进数组：

   ```json
   ["randomimitater"]
   ```

   已经有别的 Mod 就追加，例如：

   ```json
   ["别的mod", "randomimitater"]
   ```

4. 启动游戏。

> 只把 `.pmod` 丢进 Mods 文件夹是**不够**的：启动时会扫到这个包，但 `enabled_mods.json`
> 里没有对应 ID 就不会加载。两个都要有。

## 怎么确认装上了

随便进一个关卡到选卡界面，卡片在「**Mod 植物**」页签里。

也可以看日志 `%APPDATA%\Godot\app_userdata\植物大战僵尸杂交版\logs\godot.log`，
出现这一行就说明成功：

```
[RandomImitater] 已注册卡池 RandomImitaterMixed：植物 325 张 + 僵尸 290 只；……
```

> 如果看到 `package rolled back`，说明加载失败。

## 卸载

在 Mod 管理界面里选中这个 Mod 删掉，或者在 `enabled_mods.json` 里把 `"randomimitater"`
那一项去掉，然后重启游戏。

只删这个 Mod 自己的文件和它那一条 ID，**不会动其它 Mod**。卸载后所有行为回到原样。

## 常见问题

**Q：装了但游戏里看不到这张卡？**

A：确认游戏版本是 0.29.0；确认 `enabled_mods.json` 里有 `"randomimitater"`；把
`%APPDATA%\Godot\app_userdata\植物大战僵尸杂交版\ModsCache\RandomImitater` 这个文件夹
删掉再重启游戏。

**Q：装完之后过一阵子 Mod 又不见了？**

A：如果游戏是**通过启动器**进去的，启动器可能会用服务器上的同名包覆盖本地文件。
直接运行游戏目录里的 exe 就不会有这个问题。

**Q：能同时装别的 Mod 吗？**

A：这个 Mod 只新增一张卡，不修改任何原有内容（`overrides` 为空），理论上不冲突。
但它和官方模仿者共用一套变身逻辑，如果另一个 Mod 也改了模仿者，可能会有相互影响。

**Q：能改概率吗？**

A：当前概率是写死的。要改得重新编译源码，普通玩家改不了。

**Q：为什么卡片显示的阳光是 0？**

A：**刻意设成免费的。** 因为它有一定概率开出一只**敌对僵尸** —— 如果还要照常收阳光，
就等于"花了钱还可能给自己招个敌人"，难度太高。所以这张卡不花阳光。

**Q：开出植物还要另外付阳光吗？**

A：不用，全程都不花阳光。开出的植物直接就是你的。
